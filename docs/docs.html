Guía técnica de AntigravityRPC

Todo lo necesario para instalar, entender cómo se calculan tus estadísticas y personalizar tu presencia en Discord.

1. Instalación

Ejecuta AntigravityRichPresenceSetup.exe (Windows 10/11 x64). El instalador incluye todo lo necesario en un único binario Rust nativo sin dependencias externas ni runtimes adicionales.

  • Crea el acceso directo Antigravity (con Discord RPC) en el menú Inicio.
  • Preconfigurado de fábrica con el Client ID oficial (1571349694016266300) y el icono de Antigravity.
  • Si actualizas una versión abierta, el instalador cierra la instancia anterior automáticamente.

2. Modo Launcher (--launch) y Bandeja del sistema

El acceso directo Antigravity (con Discord RPC) ejecuta AntigravityRichPresence.exe --launch. De este modo abre Antigravity, monitoriza sus ventanas y termina limpiamente en cuanto cierras Antigravity, evitando procesos residentes en segundo plano.

  • Clic izquierdo en el icono del tray: abre la ventana minimalista de configuración.
  • Clic derecho en el icono del tray: abre menú rápido con Configuración y Cerrar RPC.
  • Recuperación automática del icono del tray si Windows reinicia explorer.exe.

3. Telemetría 100% local y cálculo de estadísticas

AntigravityRPC no envía datos a ningún servidor ni lee tu código fuente. Extrae metadatos locales en tu equipo y comunica directamente con Discord por \\.\pipe\discord-ipc-0:

  • Proyecto y ventana activa: annotations/*.pbtxt, app_storage.json, projects/*.json y conversation_summaries.db.
  • Días activos, horas e interacciones: agrega todas las conversaciones del proyecto desde transcript.jsonl contando días naturales distintos, horas reales e interacciones de usuario (USER_INPUT).
  • Formato mostrado: Invertido: 30d | 74h | 413 interacciones (o en inglés Invested: 30d | 74h | 413 interactions). Si estás en un chat libre sin proyecto, muestra la conversación actual.

4. Rama Git y botón Ver repositorio

Si la carpeta del proyecto es un repositorio Git, lee .git/HEAD para añadir la rama activa junto al proyecto y normaliza remotos SSH/HTTPS de .git/config para mostrar el botón interactivo Ver repositorio en Discord.

5. Opciones de configuración

Los ajustes se guardan automáticamente en %APPDATA%\AntigravityRichPresence\config.json y se aplican al instante:

Opción Por defecto Descripción
language es Idioma de Discord y de la interfaz (es / en).
show_project_stats true Muestra días, horas invertidas e interacciones del proyecto.
show_conversation_title false Incluye el título de la conversación actual dentro de un proyecto.
show_git_branch true Muestra la rama Git activa junto al nombre del proyecto.
show_agent_status true Badge indicando si el agente está trabajando o listo.
show_repo_button true Añade el botón Ver repositorio cuando hay remoto HTTPS/SSH.
